# 국방 R&D 레이더

국방 연구개발 과제·기관·공모 한눈에.

공개된 국방 관련 연구개발·연구용역 과제를 한 화면에서 찾아보는 정적 웹 페이지입니다.

- 원천: 국방기술품질원·방위사업청 공공데이터, NTIS 국가R&D, 국방전자조달(D2B) 공개 공고·입찰결과·계약, 부처 R&D 공고
- 기능: 과제 검색, 아이디어 중복 점검, 수행기관 찾기(역량 점수), 국방전략기술 분야별 현황
- 자료 갱신: 2026-10-04 13:55

공개 범위에 포함된 과제만 담겨 있어 국방 R&D 전체가 아닙니다. 분야·세부 분류와 기관 추천은 이 사이트의 추정이며 공식 분류가 아닙니다.
국방전자조달 투찰 내역은 업체명·금액·점수·결과만 싣고 대표자·연락처 등 개인정보는 싣지 않습니다.
