# 국방 R&D 레이더

**국방 연구개발 과제·기관·공모 한눈에** — 공개된 국방 R&D 과제를 한 화면에서 찾고, 내 아이디어가 이미 진행된 것인지 점검하고, 비슷한 분야를 해 본 기관과 지금 지원할 수 있는 공모를 확인하는 무료 웹 페이지입니다.

## 할 수 있는 일

- **과제 검색** — 친 낱말이 모두 든 과제를 찾고, 분야·연도·원천·기관으로 거릅니다. '자세히 보기'에 발주·수행기관·기간·금액·공고→계약 흐름·원문 링크가 나옵니다.
- **아이디어 중복 점검** — 아이디어를 문장으로 쓰면 비슷한 과제를 핵심 기술어가 겹치는 순서로 보여 줍니다. '꼭 들어가야 할 낱말' 단추로 좁히고, 못 찾으면 NTIS 에서 같은 낱말로 바로 찾을 수 있습니다.
- **수행기관 찾기** — 비슷한 분야를 해 본 기관을 역량 점수 순으로 보여 줍니다(유사 과제 수·최근 수행·진행 중·국방 발주 경험).
- **공모 중인 과제** — 마감 D-day 순으로, 재공고·유찰 이력과 함께 보여 줍니다.
- **새 공모 알림 받기** — 관심 단어(또는 '신규 공고 전체')를 걸어 두면 관련 과제가 새로 공모에 올라올 때 하루 한 번 메일로 알려 드립니다. 신청·해지는 메일 한 통입니다.
- **분야 지형도** — 국방전략기술 10대 분야와 군정책·국방인문사회 현황, 분야×연도 히트맵, 키워드 연결망.
- **국방 R&D 밖 과제 찾기** — 국방 판정에서 빠진 과제도 제목 낱말이 2개 이상 일치하는 것만 연구 협력 참고용으로 보여 줍니다.

## 자료 출처 (매일 자동 갱신)

NTIS 국가R&D 과제 · 국방전자조달(D2B) 공고·입찰결과·계약 · 나라장터(조달청 입찰공고·낙찰정보) · AX360 공모 · IRIS·IITP 부처 공고 · 공공데이터포털(국방기술품질원·방위사업청).

## 읽을 때 주의

- 공개된 과제만 담겨 있어 **국방 R&D 전체가 아닙니다.** 비공개 과제·진행 중인 사업은 이 자료에 없습니다.
- 국방 여부는 사업 → 발주기관 → 수행기관 → 제목·목표 순으로 판단하며, 판정은 운영자가 직접 확인한 것과 규칙이 섞여 있습니다.
- 분야·세부 분류, 유사도, 기관 추천은 이 사이트의 추정이며 공식 분류가 아닙니다. 판단은 참고용입니다.
- 국방전자조달 투찰 내역은 업체명·금액·점수·결과만 싣고 대표자·연락처 등 개인정보는 싣지 않습니다.
